#  Tactology Backend API

A powerful GraphQL-based backend built with **NestJS** and **TypeORM** to manage users, departments, and subdepartments. Ideal for internal organizational management tools, dashboards, or admin panels.

---

## Features

- JWT-based authentication
-  Department and subdepartment management
- GraphQL API (Code-first approach)
- PostgreSQL with TypeORM relations
- Clean modular structure with best practices

---

## Tech Stack

- [NestJS](https://nestjs.com/)
- [GraphQL](https://graphql.org/)
- [TypeORM](https://typeorm.io/)
- [PostgreSQL](https://www.postgresql.org/)
- [Apollo Server](https://www.apollographql.com/docs/apollo-server/)
